# Item Repair Hub v2.0.0-alpha.6

By DaggerHashimoto. GPL-3.0. Renewal; official app 1.7.0 or newer.

Repair selected equipment and transfer restrictions through searchable, paginated settings. This standalone edition contains 14 included repair entries. It does not add arbitrary items, offer custom skill grants, or infer missing bonuses from Divine Pride. Search finds included repairs only.

## Install and use
1. Install this mod folder or its installation ZIP through the app's mod installer.
2. Disable separate item-restriction-fix and cocytus-armor-plus12-fix mods to avoid overlapping repairs.
3. Enable Item Repair Hub. Open its Settings, search for an included item, and choose its options.
4. Click Save changes, close the mod window, then use Apply & restart in the main app.

Keep original means this option adds no permission override. An enabled base repair, item binding and other mods may still impose restrictions. Cocytus has its own bundled effects; this is not a general bonus repair engine.

## Existing experimental installations
Do not replace your alpha.4/alpha.5 experimental mod with this edition in your live world without backing up. Custom additions such as 550169 and 520062 are not bundled here. This edition neither imports nor deletes that private collection. Test in a separate data directory; disabling the custom integration is necessary to establish official-app compatibility.
